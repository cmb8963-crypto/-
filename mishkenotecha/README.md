# משכנותיך: ניהול תיקים ומשימות

הכתובת: `chaimbreuer.co.il/mishkenotecha`

| חלק | איפה | מה יש בו |
|---|---|---|
| **האתר** | התיקייה הזו (`index.html`, `css/`, `js/`) | רק קוד. אין בו אף נתון. |
| **השרת** | פרויקט Google Apps Script **נפרד** בחשבון Google | כל הנתונים: גיליון פרטי ב-Drive, משתמשים, גיבוי יומי. |

המערכת **נפרדת לגמרי** מהמערכת הפרטית ב-`/app`: יש לה שרת משלה, גיליון משלה ומשתמשים משלה.

> ⚠️ המאגר ציבורי. אסור להכניס לקוד שמות, נתוני תיקים או סיסמאות. כל המידע נשמר רק בגיליון הפרטי.

כל עוד השרת לא מחובר (`js/config.js` ריק), האתר נפתח ב**מצב הדגמה**: נתונים בדויים שנשמרים רק בדפדפן. אפשר לנסות את כל המסכים בלי שום התקנה.

---

## התקנת השרת (פעם אחת, כ-10 דקות)

1. **פרויקט חדש:** להיכנס ל-<https://script.google.com> ולפתוח **"פרויקט חדש"**. מומלץ להשתמש בחשבון Google של הארגון. שם לדוגמה: `משכנותיך - שרת`.
2. **הדבקת הקוד:** למחוק את כל התוכן של `Code.gs` ולהדביק במקומו את **`apps-script/dist/Code.gs`**.
3. **מניפסט:** ⚙ **הגדרות הפרויקט** ← לסמן "הצגת קובץ המניפסט appsscript.json בעורך". אחר כך לפתוח את `appsscript.json` ולהחליף את התוכן שלו בתוכן של **`apps-script/dist/appsscript.json`**. הקובץ קובע את אזור הזמן לירושלים.
4. **הרצת ההתקנה:** בראש העורך לבחור את הפונקציה **`setup`** וללחוץ **Run**. לאשר את ההרשאות (גיליונות, Drive, מייל).
   ביומן הביצוע מופיעים:
   - קישור לתיקייה **"משכנותיך - מערכת ניהול (פרטי)"** ולמסד הנתונים
   - **קוד הגדרה חד-פעמי** (8 תווים). להעתיק אותו, כי הוא נדרש בשלב 6.
5. **פרסום:** **Deploy → New deployment → Web app**. בשדה Execute as לבחור `Me`, ובשדה Who has access לבחור `Anyone`. ללחוץ Deploy ולהעתיק את ה-**Web app URL**.
   > "Anyone" נדרש כדי שהאתר יוכל לפנות לשרת. זה לא חושף מידע: כל בקשה נבדקת מול אסימון חתום שניתן רק אחרי כניסה עם מייל וסיסמה.
6. **חיבור האתר:** להדביק את הכתובת ב-`js/config.js` (`apiUrl`) ולדחוף. אחר כך להיכנס לאתר, ללחוץ **"יש לי קוד הגדרה / איפוס"** ולמלא קוד, שם, מייל וסיסמה (לפחות 10 תווים, גם אותיות וגם ספרות). זה משתמש המנהל הראשון.

**עדכון קוד בעתיד:** להדביק את `Code.gs` החדש, ואז **Deploy → Manage deployments → ✎ → New version → Deploy**. הכתובת לא משתנה.

**שכחתי סיסמה:** בעורך להריץ את `resetAdminPassword`. ביומן יופיע קוד חדש. באתר ללחוץ "יש לי קוד הגדרה / איפוס" ולמלא את הקוד, המייל של המנהל וסיסמה חדשה.

## מה קיים (שלבים 0 ו-1)

- **כניסה:** מייל וסיסמה לכל משתמש. נעילה אחרי 5 ניסיונות כושלים. שינוי סיסמה מנתק את כל החיבורים הקודמים.
- **יומן משימות (מסך הבית):** שלוש קבוצות: באיחור, להיום, ו-7 הימים הקרובים (מקופלת). בכל קבוצה תיקים דחופים מוצגים ראשונים. אפשר לסנן לפי תגית, מחלקה, טווח תאריכים וחיפוש חופשי.
- **שרשור משימות:** סגירת משימה נעשית בשני שלבים באותו חלון. בשלב הראשון כותבים דיווח ביצוע, ובשני בוחרים משימה הבאה או סגירת התיק. עד השלב האחרון שום דבר לא נשמר, ובסוף הכול נשמר יחד. השרת בודק לפני כל כתיבה שלכל תיק פתוח יש **בדיוק משימה פתוחה אחת**.
- **דחיית משימה:** קיצורי דרך (מחר, עוד 3 ימים, שבוע הבא). כל דחייה נספרת, והתאריך המקורי נשמר.
- **תיקים:** פתיחה עם משימה ראשונה, רשימה עם חיפוש וסינון, כרטיס תיק עם ציר זמן של כל הדיווחים, סימון דחוף, העברה להמתנה, ופתיחה מחדש של תיק סגור (תמיד עם משימה חדשה).
- **משימות כלליות:** משימות שלא שייכות לתיק, עם מחלקה ופרויקט (למשל "קורס מדריכים").
- **הגדרות:** תגיות (עריכה, השבתה), אנשי קשר מקצועיים, שינוי סיסמה.
- **הוספה מהירה:** כפתור "+" שזמין מכל מסך.
- **מקלדת:** Enter שולח טופס, Ctrl+Enter שולח מתוך שדה טקסט ארוך, Esc סוגר חלון.
- **גיבוי:** כל לילה נשמר עותק מלא של הגיליון בתיקיית "גיבויים" (30 העותקים האחרונים). אם נמצא תיק שלא עומד בכלל השרשור, נשלח מייל התראה בלי פרטי התיק.

## פיתוח

```bash
cd mishkenotecha
npm install
npm test        # Vitest: כללי השרשור + השרת כולו מול סימולציה של שירותי Google
npm run lint    # ESLint
npm run build   # בונה את apps-script/dist/Code.gs
```

לצפייה מקומית: להריץ `python3 -m http.server` בשורש המאגר ולפתוח `http://localhost:8000/mishkenotecha/`.

| קובץ | תפקיד |
|---|---|
| `js/core.js` | **כל כללי המערכת**: תאריכים לפי שעון ישראל, ולידציה, שרשור ובדיקת האינווריאנט. אותו קוד רץ בדפדפן, בשרת ובבדיקות. |
| `apps-script/src/Server.js` | השרת: כניסה, הרשאות, קריאה וכתיבה לגיליון, יומן פעולות, גיבוי. |
| `js/api.js` | תקשורת עם השרת + שרת הדגמה בדפדפן. |
| `js/app.js` | כניסה, ניתוב ומבנה המסך. |
| `js/pages.js` / `js/dialogs.js` | המסכים והחלונות. |
| `js/ui.js` | כלים: תבניות בטוחות (escape אוטומטי), אייקונים, הודעות וחלונות. |
| `tests/` | בדיקות Vitest. |
